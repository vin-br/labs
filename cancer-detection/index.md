# Cancer Detection

## Context

This project supports a clinic that wants a predictive model to detect cancerous cells from fine-needle breast biopsy measurements. 

## Dataset

`breast_cancer.csv` dataset (and its documentation) from [Kaggle](https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data?resource=download).

## Disclamer

This folder is intended for learning purposes only.
