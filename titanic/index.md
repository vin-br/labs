# Titanic

## Project overview

This work was completed in eight steps to build and evaluate a predictive model for the Titanic dataset.

1. Data import
	- Load CSV data into a NumPy array or a Pandas DataFrame.

2. Data exploration and initial processing
	- Display sample rows as a table.
	- Create visualizations relevant to the client's problem.

3. Algorithm selection
	- Identify the problem type and choose an appropriate algorithm.

4. Algorithm implementation
	- Implement the selected algorithm using Scikit-learn.

5. Model evaluation
	- Split data into train and test sets.
	- Compute performance metrics.
	- Visualize learning curves.

6. Model improvements
	- Reformat and preprocess data (feature engineering, cleaning).
	- Tune model hyperparameters.

7. Try a different algorithm
	- Implement an alternative model and compare results.

8. Cross-validation and pipelines
	- Apply cross-validation and Scikit-learn pipelines, then re-evaluate performance.
